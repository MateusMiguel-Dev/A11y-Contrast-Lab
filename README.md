# A11y Contrast Lab

Ferramenta interativa de acessibilidade criada para transformar análise de contraste em uma etapa prática do processo de design.

## O problema

Escolher cores apenas por percepção visual pode produzir interfaces difíceis de ler. O laboratório permite comparar pares de cores, visualizar componentes e registrar decisões de contraste.

## O que demonstra

- WCAG-informed contrast checking
- UI states e estados de foco
- Design de componentes
- Persistência local de decisões
- JavaScript para interação e cálculo
- Responsive design
- HTML semântico e controles nativos

## Funcionalidades

- Cores em HEX e color picker
- Cálculo de contraste
- Validação AA/AAA para texto
- Preview de card, botão e input
- Demonstração de estados de interface
- Histórico salvo no navegador
- Layout responsivo

## Como usar

Abra `index.html` em um navegador. Nenhuma dependência ou build é necessária.

## Nota de acessibilidade

As referências numéricas seguem os critérios clássicos de contraste da WCAG, mas uma auditoria real de acessibilidade deve avaliar também foco, teclado, semântica, tamanho de texto, conteúdo e contexto de uso.
